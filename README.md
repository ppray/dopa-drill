# 小茉莉练习册

> **非官方中文改编版。** 改编自 [grmchn/dopa-drill](https://github.com/grmchn/dopa-drill)（日文「ドパドリル」，MIT）。本仓库是它的非商业 fork：界面改为简体中文，题目按北京版新教材的年级编排，角色换成了原创的「小茉莉」。

每做对一道算术题，特效和音乐就会越来越夸张的计算练习。只需要浏览器就能玩。

小茉莉会帮你搬运输入的数字，答对了还会为你庆祝。题目做得越多，画面和声音就越丰富，最后变成一场庙会般的狂欢。答错了气势也不会掉，没有 Game Over。

## 特点

- 覆盖小学 1〜6 年级的 66 个计算技能：加减乘除、竖式的中间步骤输入、简便计算、小数、分数、百分数等，年级安排对齐北京版新教材（见下）
- 「我的水平」模式：从实力测试开始，随着熟练度逐步解锁下一个技能
- 按年级练习、专项练习、复习、技能树界面
- 全部答对得 100 分。一次答对率达 80% 以上，可以挑战限时加时赛，冲击 100 分以上的分数
- 音乐和音效全部由 Web Audio API 合成（没有使用任何音频文件）
- 支持手机竖屏和电脑。电脑上可以用数字键和 Backspace 输入
- 可在设置里调节动效强度，也可以静音
- 所有记录都保存在本机（localStorage），不会向外发送

## 本地运行

不需要构建。只要把 `app/` 当作静态文件目录来提供就行：

```bash
python3 -m http.server 8000 -d app
```

用浏览器打开 `http://localhost:8000/`。因为用了 ES Modules，直接用 `file://` 打开是不行的。

## 测试

需要 Node.js 20 以上：

```bash
node --test tests/*.test.mjs
```

## 部署到 Cloudflare

`app/` 就是完整的静态站点（`app/_headers` 是 Cloudflare 的响应头配置），可以直接用 Wrangler 部署。`*.workers.dev` 在中国大陆无法访问，所以 `wrangler.jsonc` 还绑定了自定义域名 `molly.openroutera.com`，国内请用这个链接：

```bash
npx wrangler deploy          # 使用根目录的 wrangler.jsonc（Workers 静态资源）
# 或者：
npx wrangler pages deploy app --project-name=dopa-drill-zh
```

## 中文化说明

- 界面文案全部改为简体中文；面向小朋友的语气，术语用国内课本说法（竖式、进位、退位、最大公因数、百分数、带分数等）
- 日语专有的「九九」「ノーカン」等概念做了本地化：乘法口诀、补签
- 字体：原来的日文字体不含简体字形，改用 Noto Sans SC（正文）和站酷庆科黄油体（大标题），数字仍使用 Dela Gothic One / Zen Maru Gothic
- 游戏名改为「小茉莉练习册」，分数单位「朵」；角色换成原创的大头贴风格卡通「小茉莉」（丸子头、头顶的红墨镜、茉莉花发饰；默认穿牛仔背心配红点领带）
- `docs/` 里的设计文档保留日文原文（描述的是原作的日本课程和原角色）

## 题目与北京版教材的对应

技能的年级按北京出版社依据 2022 年版课程标准修订的新教材编排（一上～六上，2024 秋起陆续使用），对照课本原页核对过。

| 年级 | 主要内容 |
| --- | --- |
| 1 | 10 的分与合、20 以内进位加法和退位减法、连加连减、整十数加减、两位数加减一位数（含进退位）、两位数加减两位数竖式 |
| 2 | 乘法口诀（1~3、4 和 5、6 和 7、8 和 9、混合）、表内除法、有余数的除法、混合运算（含小括号）、整百整千数加减、三位数及万以内加减 |
| 3 | 整十数乘除一位数、多位数乘一位数、两位数和三位数除以一位数、整十数乘整十数、两位数和三位数乘两位数、几分之一、简单的分数加减 |
| 4 | 除数是两位数的除法、运算定律与简便计算、近似数、小数加减、小数点移动 |
| 5 | 小数乘除、最大公因数、最小公倍数、约分、分数与小数互化、异分母分数加减、带分数加减 |
| 6 | 分数乘除、小数与分数混合计算、百分数与小数和分数互化、求一个数的百分之几、相等的比 |

说明：

- 四下、五下、六下的新版教材还没有出版，放在这几册的内容按现行版本推定：小数加减、小数点移动、近似数（新版四上没有，五上已默认会用四舍五入）、因数与倍数、约分、异分母分数加减、带分数加减、分数与小数互化、比。
- 原作的「求 x」（解方程）已删除：2022 年版课程标准把方程移到了初中，新版五上只有「用字母表示数量关系」。
